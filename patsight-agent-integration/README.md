# PatSight Agent 集成 · HTML 演示原型

## 打开方式

将页面放在同一目录，通过本地静态服务或直接打开 HTML 预览。样式、脚本和图片内嵌，不依赖额外视频或资源目录。首页约 14 MB，首次打开可能稍慢。

本地预览入口：
- 首页：01-home.html
- Agent 介绍与案例：05-agent-intro.html
- 后台接入配置：02-agent-connect.html
- API Key 管理：03-api-keys.html
- 登录回跳演示：06-login.html
- 简约首屏对比：07-home-simple.html（仅评审对比，未增加本期案例）

## 页面与交互

- 首页保留首屏 Agent 浅蓝轻卡片，在“了解 Agent 集成”旁增加“观看演示”。导航为产品特色 / Agent 集成（NEW，英文 Agent）/ MolVision 结构识别 / 案例 / 联系我们；MolVision 无 FREE 标签。
- 公开介绍页展示两步接入、四项能力、一个完整主案例和效果评测摘要 Demo；不重复展示其他小案例。
- 后台接入配置页在接入步骤下方增加“看看如何调用”主案例。Agent 集成仍是用户中心下方的同级入口，模块包含接入配置和 API Key 管理两个页签。
- 五个主页面支持中文 / 英文；官网沿用原语言按钮，后台和登录页新增中文 / EN 切换。页面跳转与登录回跳保留语言偏好；用户自定义 Key 名称不翻译。
- 介绍页安装入口进入 06-login.html?next=02-agent-connect.html；Key 入口进入 06-login.html?next=03-api-keys.html。演示登录只允许回跳到这两个页面，不收集账号、密码或 Key。
- API Key 列表只保留名称、Key、创建日期、最近使用日期、操作；创建、复制、改名和删除确认均为本地模拟，刷新重置。

## 案例与视频占位

主案例为“提取专利中的化合物结构与活性数据”。视频位置提供可点击的分镜播放器，展示安装 Skill → 本地配置 Key → 发起任务 → 查看结果，支持播放 / 暂停、进度拖动、章节切换及关闭。

这是 32 秒交互占位演示，不是实录视频。示例结果为虚构布局数据，没有执行安装、调用服务、导出真实结果或产生费用。开启减少动态效果时默认暂停。

反应路线覆盖以实际支持为准，MolVision Agent 调用入口仍待确认。主案例只对应结构与活性提取，不表示覆盖全部能力。

## 效果评测 Demo

介绍页主案例下方使用一张对比表，仅展示结构提取准确率、活性提取准确率、反应提取准确率、IUPAC 名称提取准确率四行，对比 Claude 单独使用与 Claude + PatSight。每行只保留一个核心指标，反应 / 合成路线仅评测已支持范围。准确率按正确提取记录 / 全部提取记录计算，活性与反应记录要求相关字段及关联均正确；遗漏、无输出与完整性留在真实报告中说明，耗时和人工修正量作为补充。

所有结果均标记为“待实测”，没有虚构分数、优胜结论或实际评测报告。集成方案的列高亮仅表示本期方案，不代表优胜。页面已移除表格下方的附加说明和评测口径折叠区；中英文切换同步更新。

本 Demo 不运行模型、不上传专利、不调用接口。真实测评完成后再补充样本量、实测结果、限制和完整报告入口。

内部一致性验收：在算法版本、输入、参数及处理流程一致时，核对直接调用与 Skill 调用的 PatSight 原始输出是否一致，并单独检查 Agent 最终整理是否遗漏或改写。该项不作为对外评测的第三组，Skill 本身不是新的提取算法。

## 原型边界

- 不修改 PatSight 原产品源码，不实现真实登录、鉴权、计算或扣费。
- 只使用 demo_ Key；不要输入、保存或上传真实凭据、个人或客户敏感数据。安装说明仍为评审草稿，不是正式安装包，不提供未经验证的命令。
- 正式服务的鉴权、租户隔离、费用确认、撤销生效和在途任务处理由服务端实现，不能由 Skill 文案代替。
- “联系我们”当前仍链接到简约首页，仅供样式评审；正式产品应保留原联系入口。原首页的 MOLAGENT 视频未内嵌，本期 Agent 分镜演示不依赖该视频。
- 04-task-demo.html、截图、压缩包、模板、构建目录与生成脚本不属于本期正式交付。
- 本次修改为本地 Demo 更新，不代表 GitHub 或 Pages 已同步。仓库文件链接也不等于可直接浏览的网站。

## 维护

本期直接维护独立 HTML；旧模板和构建脚本未同步，不应直接重新生成覆盖当前版本。
