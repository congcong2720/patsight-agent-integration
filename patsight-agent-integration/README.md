# PatSight Agent 集成 · 独立 HTML 原型（修订版）

## 视觉调整

保留简洁内容，使用 PatSight 浅蓝介绍横幅、横向接入操作条、四列能力目录、分段式页签与浅蓝表头。避免继续沿用 Nexus 的左右分栏英雄区、双步骤卡、胶囊创建按钮和两列大能力卡。原产品侧栏与官网首页主体保持不变。

## 本次交付

官网导航统一为：产品特色 / Agent 集成（NEW，英文 Agent）/ MolVision 结构识别 / 案例 / 联系我们，右侧语言与登录；移除 MolVision FREE 标签。后台模块仍叫 Agent 集成，保持简短。

公开页“获取安装说明”和“配置 API Key”先进入 06-login.html，再按 next 参数返回接入配置或 KEY 管理。该页仅演示登录路径，无凭据表单，无真实鉴权。正式产品应接现有登录系统，已登录直接打开目标页；此独立原型固定演示未登录路径，不伪装真实会话。

- 01-home.html：导出原 Vue 首页，导航“产品特色”后保留“Agent 集成”，产品特色内容之后增加轻量接入提示；原首屏、轮播与产品内容不重组。
- 05-agent-intro.html：独立介绍页，复用原首页导航、样式体系和页脚，支持中英文切换。开始接入按钮进入后台演示配置页。
- 02-agent-connect.html：产品后台“Agent 集成 / 接入配置”。
- 03-api-keys.html：同一模块下的“API Key 管理”页签。

后台沿用原窄图标侧栏和蓝底白色内容区。用户中心下面新增同级“Agent 集成”，下方保留帮助中心。现有模块图标取自 patsight-app-v2/src/app.config.ts；其他模块只保留位置，不模拟整套产品。

双击 HTML 打开。样式、脚本和图片内嵌；四页放一起可相互跳转，单独发送也可独立展示。首页因内嵌原轮播截图约 14 MB，不再依赖图片目录。

## 演示边界

- 原首页与应用源码未修改；导出构建时临时插入导航入口，原文件不变。
- 官网介绍面向接入说明；配置与 KEY 管理只在后台。原型直接展示已登录演示状态，不实现真实登录。
- KEY、余额、验证和任务均为模拟，不上传文件、不访问真实 API、不扣费、不保存真实密钥。数据刷新重置，页面间不共享。
- KEY 页面只保留名称、Key、创建日期、最近使用日期、操作五列；复制图标跟在脱敏 Key 后，编辑/删除采用图标。删除后从演示列表移除，不另做已撤销列表。真实撤销与在途任务规则待确认。
- 接入使用页和官网介绍页只保留两步接入与四项能力介绍，不展示余额、验证表单、复杂命令配置或多组 FAQ。
- MolVision CLI 入口、反应与合成路线覆盖、KEY 配置方式、快速验证和余额查询接口及排期待确认。
- 扣租户 Credits 不等于取消按页计价。Skill 下载内容仅为评审草稿，不是正式安装包。
- 原首页本地 public/MOLAGENT.mp4 缺失，保留视频区与海报，但独立 HTML 不包含该视频。其他原站外部体验、联系链接按原样保留。
- 离线导出使用系统字体回退，不依赖 Google Fonts；增加轮播容器最小宽度约束，裁切原入场动画的水平溢出，不改变原内容。
- 04-task-demo.html 是上一版补充演示，不属于本次主交付，不纳入更新后的压缩包。
